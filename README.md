# Kochy's – Website

Dieselstraße 1A · 40880 Ratingen · 02102 5589497 · info@kochys-ratingen.de

- `index.html`: Seite mit Design, Aufbau, Warenkorb und Bestellablauf (eine Datei, kein Framework)
- `menu.js`: **Speisekarte** – Gerichte, Preise, Auswahl (Fleisch, Beilage, Dressing, Dip, Getränk) und Extras nur hier ändern
- `impressum/`, `datenschutz/`: Rechtstexte (gleiche Adressen wie auf der alten Seite)
- `img/`: Logo, App-Icons, Fotos · `fonts/`: Outfit und Fredoka, lokal eingebunden
- `manifest.webmanifest`, `sw.js`: Web-App (bei Änderungen die Cache-Version in `sw.js` hochzählen)

Einstellungen (Bestellung per WhatsApp/E-Mail, Liefergebiete, Mindestbestellwert, Liefergebühr, Zahlungsarten, Öffnungszeiten, Gerichtnummern) stehen in `index.html` oben im Script unter `SHOP`.
